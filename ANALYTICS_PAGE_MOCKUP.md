## 🎨 Цветовая палитра

### Основные цвета:
- **Primary**: `#6366f1` (индиго) - акценты
- **Success**: `#10b981` (зеленый) - завершенные задачи
- **Info**: `#3b82f6` (синий) - в работе
- **Warning**: `#f59e0b` (оранжевый) - high priority
- **Danger**: `#ef4444` (красный) - просрочено/urgent
- **Gray**: `#94a3b8` (серый) - pending

### Градиенты для графиков:
```css
/* Линия завершенных */
background: linear-gradient(180deg, 
  rgba(16, 185, 129, 0.2) 0%, 
  rgba(16, 185, 129, 0.05) 100%
);

/* Donut chart */
colors: ['#10b981', '#3b82f6', '#94a3b8', '#ef4444']

/* Heatmap */
colors: ['#f0fdf4', '#86efac', '#22c55e', '#15803d', '#14532d']
```

## 📊 Примеры интерактивности

### Hover на графике:
```
  ╱╲
 ╱  ╲    ← 📍 15 ноября 2025
╱    ╲     Создано: 12
         Завершено: 10
         Просрочено: 1
```

### Клик на день в heatmap:
→ Переход в календарь на эту дату

### Клик на тег в "Топ-5":
→ Открывает фильтр с этим тегом

### Клик на бар приоритета:
→ Показывает список задач с этим приоритетом
