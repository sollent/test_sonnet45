# План реализации: Базовый функционал задач

- Frontend пиши как будто ты Senior Frontend Vue.js Developer
- Быстрая работа - никаких задержек UI
- Очень важна адаптация под мобильные устройства! Вполть до того, что в будущем это будет отдельное полноценное мобильное приложение на capacitor, поэтому важно продумать детально UI/UX.

## Цель первого этапа
Создать минимально работающее приложение для управления задачами с современным UX/UI

## Основные user cases

### 1. Создание задачи
- Пользователь нажимает "+" или кнопку "Добавить задачу"
- Открывается форма/модальное окно
- Пользователь вводит название задачи (обязательное поле)
- Может добавить описание (опционально)
- Сохраняет задачу - она появляется в списке

### 2. Просмотр задач
- Задачи отображаются списком, сгруппированные по датам (сегодня, завтра, конкретные даты)
- Каждая задача показывает: чекбокс, название, время (если есть), теги
- Плавная прокрутка списка

### 3. Работа с задачей
- Клик на чекбокс → задача помечается выполненной (зачеркивается, переносится в "Выполненные")
- Клик на саму задачу → открывается детальная панель справа
- В деталях можно редактировать все поля

### 4. Установка дедлайна
- В форме задачи есть поля "Время начала" и "Время окончания"
- Пользователь может выбрать дату и время через удобный пикер
- Задачи с дедлайном показывают время справа в списке

### 5. Добавление подзадач
- В детальной панели задачи есть секция "Подзадачи"
- Кнопка "Добавить подзадачу" 
- Подзадачи отображаются списком с чекбоксами
- Каждую подзадачу можно отметить выполненной отдельно

### 6. Теги
- В форме задачи есть поле для тегов
- Пользователь вводит тег через запятую или выбирает из существующих
- Теги отображаются как цветные таблетки рядом с задачей
- Можно фильтровать задачи по тегам (клик на тег в боковом меню)

### 7. Редактирование и удаление
- В детальной панели кнопка "Удалить" (внизу, красная)
- Любое поле можно отредактировать прямо в детальной панели
- Изменения сохраняются автоматически

## Требования к дизайну
- Светлая тема по умолчанию
- Минималистичный интерфейс без визуального шума
- Плавные анимации (появление/исчезновение модалок, отметка задач)
- Большие кликабельные области
- Приятная типографика и spacing
- Современные rounded corners, тени для elevation
